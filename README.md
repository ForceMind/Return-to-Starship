## 故事

2020年，林青宇在研究所收到一份报告：秦岭山沟里发现了一颗直径超过十米、来历不明的白色球体。他与李阳等专家进入空山基地，从目击影像、山地测量和非接触实验开始，逐步面对一件越来越无法用人类现有技术解释的东西。

在遥远的星际，载着数百万海兰幸存者的米克号仍然寻找新的家园。一次黑洞附近的探索使库克和五号探索者失联，舰长利菲克不得不在寻找弟弟、重新调查父亲米克的死亡、保护全舰以及追求新世界之间作出艰难选择。

本次D路线完整创作版将两条主线在后半部交汇，写出受限的星际联系、五号返航和两种文明面对人工智能与公共责任的不同方式。这是**新增的创作性结局**，不是已经恢复的作者早年完整终局。
