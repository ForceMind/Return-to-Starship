# 重返星舰 / Return-to-Starship

长篇小说《重返星舰》的正式文稿仓库。

这里保存原著设定、人物关系、故事大纲、中文正文、修订记录，以及后续的网页阅读器。**作品内容只以本项目已经提供并核实的原始材料为准，不从别的小说或讨论移入任何设定。**

## 项目结构

- `docs/00-sources.md`：项目材料来源与确认记录
- `docs/01-canon.md`：已核实的世界观、人物、故事事实
- `docs/02-outline.md`：全书及各章的结构规划
- `docs/03-workflow.md`：写作、修订和 Git 版本流程
- `manuscript/zh/`：按阅读顺序编排的中文正文，从引言开始
- `web/`：面向读者的阅读网站（后续阶段）

## 正文规则

1. **先核实原始文件，再改动剧情。** 任何未核实的内容不得标记成既定事实。
2. **从引言开始。** 每个章节使用一个独立 Markdown 文件。
3. 创作草稿、核对稿、定稿用明确的状态和 Git 历史区分。
4. 不以“本地曾经生成过”为理由把其他作品导入本仓库。
5. 网页从经确认的正式正文构建，绝不反向篡改原文。

## 当前进度

GitHub 仓库及初始管理结构正在建立。**原项目文稿和设定尚未在这个会话的可检索文件中成功读取，因此正文与世界观保留为空，等待核对来源后再写入。**
