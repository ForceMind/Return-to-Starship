## 故事

2020年，林青宇收到一份报告：秦岭山沟里出现了一颗直径超过十米的白色球体。他与李阳等专家进入空山基地，从目击影像、山地测量和非接触实验开始，逐步面对一件无法用现有技术解释的东西。

遥远的米克号载着数百万海兰幸存者寻找家园。弟弟库克在黑洞附近失联，舰长利菲克被迫重新调查父亲米克的死亡，并在个人亲情、全舰安全和寻找新世界之间作出选择。
