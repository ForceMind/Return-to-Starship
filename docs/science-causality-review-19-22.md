# 第十九至第二十二章｜双端通信、时间因果与返航工程审校

**第二轮审校工作底稿｜2026-10-11。状态：基于已提交D路线创作稿的内部连续性检查；不是现实科学已证实的技术报告，也不意味着作者批准D路线核心谜底。**

## 1. 先分清哪些是故事事实，哪些是角色推断

- 原作者已确认的核心事实：米克号、五艘探索者、库克随五号在黑洞附近失联；米克号某时距地球约 **46.7光年**，海兰距米克号约 **8.9光年**，属于不同参照；海克亲手关闭母星睿海，舰载瑞娜与睿海不是一个AI。
- 新写的D路线结果：地球秦岭白球被确认为五号探索者；库克在保护模式下生还，经受限几何状态返航；父亲米克之死与瑞娜的错误安全程序有关。**这些拟定结果仍需作者审定**。
- 科幻虚构机理：黑洞邻近极端环境的短时空间几何联络。它可在D路线里传输有限结构化信息、在一次特殊窗口恢复**五号小型载荷**，但**并非**已得到现实物理验证的可控虫洞，不让地球立即掌握超光速交通，也不让米克号数百万人直接迁徙。

## 2. 分为三种完全不同的距离与时间

| 量 | 参照和含义 | 编辑要求 |
| --- | --- | --- |
| 46.7光年 | 原稿某状态下米克号与地球的空间距离；地球研究组在第19章得到了接近此数字的**候选空间解** | 不等于两端日期相同、母舰与黑洞标记器之间距离相同，也不等于本地观测可精确同步远端生命状态 |
| 8.9光年 | 海兰母星与米克号的空间距离 | 不能偷换成“海兰距地球8.9光年” |
| 数据链中继延迟 | 母舰正常链路→黑洞附近探测器/标记通道→特殊几何关联→地球五号本地接口，反向类似 | 每一段都可能缓冲、重复、丢失和延迟；**没有共同的绝对时钟，也没有证明普通无线电能瞬间跨越46.7光年** |

## 3. 不把“两条叙事线交替”误写成真实世界同一时刻

| 局部因果阶段 | 空山／地球本地可确认之事 | 米克号／黑洞探测器可确认之事 | 跨线推断条件 |
| --- | --- | --- | --- |
| A：最初 | 白球已经出现在秦岭；无普通大气高速进入轨迹的可验证证据；第16—18章建立低照度输入—响应 | 五号失联，米克号已朝A31航行；黑洞侧有残余探测器资料 | 不能说地球白球出现当天＝五号失联在母舰当地同一天 |
| B：单端状态 | 取得有五单元前缀、第五项异常的资料；星图候选解接近46.7光年 | 由库克旧附件与探测器记录得知有限几何标记通道；母舰获取延迟数据 | 两端各自初步证据并不自动构成直接认证 |
| C：互为挑战 | 地球先保存本地随机挑战与回执，后来发现不由本地输入解释的短时序列 | 米克号独立生成随机挑战，经标记器发出，过不确定延迟读取部分返回 | 独立随机数与双方保存的来源记录使离线交叉核查成为可能；不能把未知延迟假装零 |
| D：许可 | 田虎义负责当地撤离、几何允许范围和**短周期可撤销许可**，五号本地接口确认；失联默认停 | 库克出航前的失能授权与米克号多方许可，经中继**提前**给五号；母舰不负责远程实时操纵地球现场 | “收到命令”≠“同意开始”。须两端不同权限都满足才可启动 |
| E：第一次中止 | 第21章地质指标异常，地球安全岗位撤回本地许可；五号在当地立即冻结动作 | 米克号后来才收到停止日志，无法按自己的本地时钟与地球秒数直接同步 | **不能写成**停止请求先跑到46.7光年外的舰长室、获批准后再传回地球才停止 |
| F：第二次启动 | 经地面独立核对、修改允许范围，重新给予一次有期限许可；球体离开地球 | 标记器/五号按已有签署授权和自身剩余资源执行，母舰收到延时回执 | 不能宣称所有几何问题完全解决，也不能把一次航行设计成无限复用的公路 |
| G：回收 | 地球仅收到有限“完成”状态，没有医学身份确认，也不掌握远方文明全部语言 | 五号进入黑洞侧可追踪区域，不是立刻停在母舰门口；接应设备提供有限支援，导航到受控回收区，医疗最终确认库克存活 | 母舰信息与地球可知状态保持不对称，跨端一次性窗口关闭后不可实时交谈 |

## 4. 审校中已经实际写回正文的修正

- **19《四十六点七》**：压缩重复的星图/五对象发现；用待批准的研究摘要对照条件模型、历元、单位和距离误差，避免一位角色从漂亮匹配直接跳到确定46.7光年的地点。第五项成为需要设计实际挑战的“未结状态”。
- **20《有人必须留下》**：补写有限信息的**物理/叙事中继路径**，强调地球本地五号接口、异常几何标记端、黑洞侧无人探测器与母舰常规数据链的不同工作步骤与未知延迟。
- **21《返航》**：补写母舰**预先签署授权**与五号在地球的**本地短时安全许可**独立验证；实际停止在地球本地完成，母舰仅迟后收到日志；五号从地球转移到黑洞侧**可追踪区域**以后仍需接应、有限能源支持和医疗核实，而非瞬间停靠远方星舰。
- **22《重返星舰》**：把“海克动机”和“米克事故责任”的后设总结改成有原始声音、旧维修求援、独立听证、灰色缺失字段和瑞娜明确修订指控的戏剧场景。仍属于D路线拟定结果，不追认历史S1已经写出这些答案。

## 5. 下一阶段必须继续追问、不可装作已经全部解决的问题

1. **时间坐标与可观测因果**：当前文本只确认各端局部先后顺序，仍没有解释几何通道怎样避免全局因果悖论；如作者最终采用D路线，建议将“无统一时钟与端点单向条件”进一步确定为明确的虚构物理公理，避免在其他章节无意中出现可以向过去发送任意指令的技术。
2. **星图46.7光年的解释**：一组存储在五号内的信息为什么与米克号后来所在位置一致（相对运动、参考历元、定位数据更新、误差），第19章只是模型解；正式科学审校需检查这一点。**不能把46.7的对应当成尚未证明却恰好完美的密码。**
3. **船舰航行与回收距离**：米克号已撤往A31，黑洞附近是标记器原始位置。第21章增补了后续接应与能源支持，但尚未量化母舰与标记器之间距离、接应所需舰内周期、五号储备及医护可达性。正式终审前必须选择自洽的轨道/路线模型；不得凭空填入几小时的回收速度。
4. **授权与安全机制**：地球端停止许可已在本地兑现；下一稿可以在第21章早期明确五号的原有预载安全设计，使“命令失联自动停机”在返回高潮前得到更充分铺垫。模拟系统仍不能代替真实运行保证。
5. **母星灾难伦理与责任**：第22章已改用双份不同来源的录音/求援展示海克的决定，但尚需在全书前段更早铺垫睿海资源规则与人工备份失效，避免终章一次性给出全部解释。
6. **避免专业术语替代文学后果**：即使机理自洽，仍需让吴凌琳、胡海、刘波、田虎义、普通维修者及星舰生活区的个人处境参与高潮，不应只在结局让他们读一份胜利报告。
