## 物理、舰务与信息术语

| 光压帆／光帆 | photon sail / light sail | 可使用 *light sail* 作为普通叙述；指激光驱动时写 *laser-driven light sail*，不等于无惯性/超光速 |
| 光压推进 | photon-pressure propulsion | 指光子动量推动，不写成传送/折跃推进 |
| α漩型黑洞 | alpha-vortex black hole | 作品内部的**虚构分类**，不要当成现实天文学认可分类 |

## 叙述与风格规范

- 目标是适合原生英语科幻读者阅读的小说，避免机械保留中文“他沉默了片刻”“这并不代表”式重复表达；关键人物犹疑与证据边界不可无故删去。
- “林所长”：通常译为 *Director Lin*，首次视上下文说明研究机构职务，不机械写 *Institute Chief*。军衔“少将”：*major general*，按英文惯例是否大写取决于称谓位置。
- 海兰文明拥有独立文化；英语不需要把每个角色改成英美人名，也不应让其对话凭空引用西方历史或地球特有文化。
- 每章保留第三人称视角知情边界：地球科研组在建立可核验通信以前，不知道利菲克、库克、瑞娜等具体名字；米克号也不能因有限返航数据立刻熟知地球社会。
- 任何D路线尚待批准的内容，只允许作为**当前未出版译稿的候选剧情**，在作者最终确认中文前不进入可发布译文。
- 英文书名/章名可做自然化处理，但每章00—22的固定ID不能改变；专名需要作者最终批准的罗马拼写统一冻结。

## 待作者最终确认的词汇事项

1. 外星人物采用上述拼音式音译（Mik, Lifike, Kuke, Haike, Rena等），还是另行选择更自然的英语音形。
2. “龙”航天计划是正式称 *Project Dragon*，还是保留中文原音 *Long*。
3. “空山基地”正式英文名采用 *Kongshan Base* 还是经审定的意译。
4. 部分星舰组织、历史许可字段应采用偏法律、工程还是文学化的正式英译。

**不要求立即回答这些问题才继续中文终审**；正式开译前集中确定，避免23章翻译后全局改名。
