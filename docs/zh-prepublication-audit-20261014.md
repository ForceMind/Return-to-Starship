目前 `web/content-manifest.json` 应保持：

- `editorial["zh-CN"] = "draft_under_review"`
- `editorial.en = "not_started"`
- `content.en = null`
- `approved_source_zh_sha = null`
- `publish_approved["zh-CN"] = false` 与 `publish_approved.en = false`

**本表的SHA只作为修订检测基线，不能写入`approved_source_zh_sha`当成作者批准。** 中文某章一旦经过作者确认，需重新获取最新SHA，在清单上记录批准的版本，并作为唯一英文学译来源。小说网站不因GitHub仓库公开而自动向公众发布任何待审版本。
