3. 原稿 `docs/canon.md` **C19—C20**：星舰距地球46.7光年、海兰距星舰8.9光年是不同参照，不能把本次救援中A31至黑洞侧局部回收区的600万公里混成46.7光年。
4. 地球端在第11—14章仍不知瑞娜、库克或米克号姓名；到第18章仍只能验证未知装置的结构化输出，不能提前证明外星生命或已确定完整器件身份。
5. 第21章D路线拟定结果：库克由经过认证的五号返回，**不等于**米克号或地球人类已获得可不限载荷、可不限次数的跨距通行。

## 三、返航量化模型（工作假设，不是真实科学）

详见 [科学因果专项第6节](science-causality-review-19-22.md)。正文在本批加入的工作假设为：A31母舰距预计回收区约600万公里；预置无人艇距五号预计落点不超过20万公里；接应艇机动上限36舰务小时，五号本机生命保障剩余约48舰务小时；完成隔离补能后最低保护可持续不少于12个舰内标准日，亚光速返舰预计6—8个标准日。

名义缓冲为：首次接应 **48−36＝12舰务小时**；后续运送 **12−8＝4舰内标准日**。这些不代表确定保证，它们都取决于实际航路、机动修正、储备真实性和接口可靠性。**小说中的几何连接仍为虚构，不能说已经解决现实黑洞可穿越性或全局因果问题。**
