## 文学翻译原则

- 中文内容优先：场景、人物的知识边界、叙述视角、科研不确定性与科幻虚构物理均不能在英文里凭语感擅自升级为结论。
- 英文文学表达优先自然：允许重组句法、削减中文无意重复的语气、调整文化说明位置，**不允许改变事件先后、人物立场或缺失证据的确定程度**。
- 地球人物采用标准中文名拼音的工作规范（例如 Lin Qingyu、Li Yang），不改成任意英语名；外星人名没有原作者正式罗马字形时采用可读的**暂定音译**，集中在词汇表，待作者确认后统一替换。
- 人名与舰名区别：`米克`人物、`米克号`舰船在英文里可用 *Mik* 与 *the Mik*，但不能出现英文只凭一处“Mik”就混淆船与父亲的上下文。
- 地球距米克号46.7光年、海兰距米克号8.9光年**参照点不同**；“光压帆”与“激光驱动光帆”亦不可混写成已经成熟的超光速技术。
- 讲“已收到/已处理/已同意/已完成”时，英文必须稳定区分 *received / processed / approved / completed*，这是米克号历史调查的重要谜题，而非普通词汇差异。
- 对所有未确认的谜底、AI意图、时间同步、空间定位都用表达对应置信程度的英文，不在译文中突然断言。

## 双语网站预期行为

双语切换时尽量留在同一章节与相近段落。若另一个语言尚未翻译或未获发布许可，应展示明确的“该译本尚未发布”，并提供回到当前语言的入口，**不能空白页、404或自动暴露未审译稿**。

独立追踪 `(locale, chapter_id)` 的段落进度；共享书签的章节ID和返回目录位置，但不假定不同语言的文本段落数量相同。中文主目录与英文主目录的章名可以不同，顺序必须一致。
