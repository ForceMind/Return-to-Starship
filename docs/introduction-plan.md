# 引言结构研究与暂缓记录

依据：S1-M01“序章”；S2-M02只是历史助手改写。正式文件目标 `manuscript/zh/00-introduction.md`，目前未创建，以免空白或改写稿被误认成完整引言。

原始作用：以一个可信的科研日常场景，把个人命运转成文明命运；报告分两次抵达，科学疑点与保密流程逐层增加；进入空山基地形成长期主线承诺。它并非灾难预告或时间回滚场景。

建议叙事：林青宇近距离第三人称；人物限于原稿五专家和田虎义等接送军官；场景依原稿从办公室到基地。报告必须是白球发现及勘查信息，不换成引力波定位海底。首次来电保留李阳既兴奋又急迫、隔壁却打电话的异常感。扩展应利用等待、证件被收走与路线未知的具体体验，而非添加虚构实验结果。

允许的语言工作：纠正明确语病、重复和节奏，增加已有动作的感官呈现，保留未知范围。不擅自写家属、秘密预言、白球回应、芽、时间重置或五号身份。

审校发现：原稿“中将”与两中校、词语“调动”等疑似错字可进入编辑标注；资料归档保留原文。引言应避免提前断言美国武器猜测为真、低温就是超自然现象、五专家已知完整计划。原文“最后一次进来”是预叙，是否保留其力度须结合终局。

本轮暂缓：三页全部可访问正文已经读完，但未核实到作者最终确认的完整后半部与结局；后续助手大纲互相冲突。作者明确要求在关键原大纲不足时不编造引言，本轮交付恢复档案与写作工作包，未把历史改写作为新正式稿。

恢复后下一步：先确认完整原剧情，再从本引言工作包开始文学改写并完整审校，之后进入第一章“星舰”。
