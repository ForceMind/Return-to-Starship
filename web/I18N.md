# Return to Starship｜双语网页阅读器语言与内容规范

**已确认目标：中文原著＋英文文学译本＋同一网站中英切换。状态：2026-10-14已形成规格；网站尚未开发、部署。** 本文不意味着目前可以发布未经作者批准的D路线创作初稿。

## 页面与语言路由

| 内容 | 中文 | English |
| --- | --- | --- |
| 首页 | `/zh/` | `/en/` |
| 目录 | `/zh/chapters` | `/en/chapters` |
| 引言 | `/zh/read/00` | `/en/read/00` |
| 第N章 | `/zh/read/NN` | `/en/read/NN` |

具体URL仅是**待实现的网站路由约定**，不是已经存在的部署地址。语言可由页眉清晰的“中文 / EN”选择器切换；同时保持键盘可达、语义清楚和良好的无障碍标签。默认为上次选择的语言；首次访问优先浏览器语言，仅在有对应已发布内容时提供切换。

## 章节、翻译进度与发布状态

- 从 [`web/content-manifest.json`](content-manifest.json) 读取稳定 `id: "00"…"22"`；同一个ID代表两语的同一章，标题可独立本地化。
- 中文资源路径为 `manuscript/zh/...`；英文目录现只有 `README.md`，**不对 `en` 为 null 的章节生成英文正文路由**，也不虚构英文已完稿。
- `publish_approved` 默认为 **false**。只有明确获得作者对目标语言和目标版本的发布许可、且内容已审定后才可开放正式阅读页。
- 若对照语言暂未翻译、待同步或未获批准：保留当前页，显示“英文版尚未发布”或 *English edition not available yet*；不要静默回退成未审稿、不要显示空页面或404。
- 译文必须有指向已批准的中文源文件SHA；中文更新后若SHA不一致，英文应标记“需同步”，正式站继续使用之前已批准的稳定版本，直到新版也获审定。

## 阅读位置与本地阅读设置

- 每一章记录 `{locale, chapterId, anchor, progress}`；语言间共享作品和章节编号，但不盲目复制滚动的像素位置（中英文段落长度不同）。
- **按段落建立可选对应锚点**：每章在编辑阶段由中英段落对照表标识主场景或锚点，切换语言时优先保持相近的场景或段落；对应缺失则回到该章开始并提示。
- 阅读设置包括字号、行距、正文宽度、深浅主题、字体家族、段落间距。中文/英文可以各自保留适宜的字体排印，但UI操作方式一致。
- 本地阅读进度优先保存在用户设备；不需要用户登录才能正常阅读。避免将全书阅读习惯或语言偏好未经用户许可上传到外部服务。
- 目录顺序固定00—22；前一章/后一章及连续阅读不因英文标题调整而改变ID。

## 正文格式、导航与SEO

- 每种语言都提供正确的 `lang` 属性与字型排版；中文标点和英文引号分别按自己的排印习惯显示。
- 文章标题层级采用章标题、场景分隔、正文段落；不把审校说明、`docs/`、`sources/`或未批准的D路线候选设定渲染到正文。
- 正式发布时为语言对应页互加 `hreflang="zh-CN"`、`hreflang="en"`，只对**实际存在且已批准发布**的页面生成SEO入口。
- 公共站点可显示双方语言的章节标题和状态，但只把实际发布语言设为可阅读链接；不可用Google索引/搜索结果绕过未批准内容。

## 版本与测试用例

1. 只有中文第01章已正式发布时，`/en/read/01` 不显示未审英文文本，切换按钮说明英文未就绪。
2. 第10章在中文修订但英文仍引用旧SHA时，不能自动把不一致译文发布；提示需要同步。
3. 在中文第07章段落中间切换英文时，若有对应锚点应回到相近位置；没有则从第07章开始，而不是跳第06/08章。
4. 中文长标题、英文标题、深色模式、手机窄屏时语言切换与上一章/下一章操作不能遮挡正文。
5. 离线或存储不可用时仍能阅读已加载的公开文本；不依赖登录。
6. 公开内容列表与GitHub真实已审版本一致，不靠写死23章的空英文正文来伪装完成度。

## 开发与托管边界

完成中文作者审定、英文文学翻译与对读后，再实施网页阅读器或根据作者新的明确指令建立仅内部可看的预览。技术可选择轻量静态站与无后端的章节清单；本文件不预先保证某个域名、部署平台或已上线服务。
