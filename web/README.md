# 《重返星舰》网页阅读器

当前是**未部署的中文审阅预览**：从仓库23篇Markdown生成首页和完整章节页面。英文0/23，界面保留“English · 待译”，不创建空译文路由。D路线与中文正文均待作者审定。

## 技术选择

采用Node.js静态构建与原生HTML/CSS/JavaScript，无第三方运行或构建依赖、无数据库、无读者账号。正文随Markdown重新构建，不复制到另一份手工维护的数据中。静态页面可直接由常规静态托管服务提供；本次不注册托管、不部署。

选择这一实现是因为作品以长文本、固定章节和设备本地设置为主：页面在脚本未运行时也能阅读，交互只负责目录、排版和进度。双语内容将来仍按manifest中的同章ID扩展，中文优先。

## 已实现

- 作品简介、23篇目录、目录搜索与当前章标记；章末上一章/下一章、回目录，Alt+方向键切换。
- 手机/平板/桌面宽度规则；中文衬线正文、严格换行规则、首行缩进、场景分隔。
- 深浅主题及系统默认；字号16—30、行距1.5—2.6、宽度560—960（实际宽度受屏幕限制），设置保存。
- 每章独立保存位置、首页继续阅读及全书估算进度；段落文本摘要作为锚点，前面插入段落不会改变现有锚点，段落删除时退回比例定位。
- localStorage损坏或不可用时可继续阅读；不上传阅读记录。原始HTML被转义，不将正文当作可执行代码。
- 明确的预览与正式构建模式；默认正式构建须23篇均获得作者发布许可、作者审定状态和完全匹配的当前源blob SHA。失败时不保留旧的正式构建目录。

## 本地命令

在仓库根目录运行，Node.js 22及以上，无需npm install：

```sh
node scripts/check-manuscript.mjs
node web/build.mjs --preview
node --test web/test/*.test.mjs
node web/watch.mjs
```

`--preview` 生成 `web/.preview/index.html` 与 `web/.preview/zh/00.html` 至 `22.html`。watch监听正文、manifest和阅读器源码变动后重新生成预览；它不启动服务器。需在具备静态HTTP预览能力的开发环境中打开页面，ES模块不能依赖直接file://打开。构建文件已gitignore，源码和Markdown保存在仓库。

```sh
node web/build.mjs
```

以上为正式构建，当前应当失败：所有 `publish_approved` 仍为false。将来确认出版版本后方可生成 `web/dist`。**没有部署脚本或自动部署工作流**；预览的noindex不等于身份访问控制，不应将本地预览目录误上传为生产作品。

## 结构

| 文件 | 职责 |
| --- | --- |
| `content-manifest.json` | 稳定章节ID、语言内容、编辑/发布许可与批准源SHA |
| `build.mjs` | 转义Markdown、生成静态页面/稳定段落锚点、核对发布许可 |
| `assets/reader.js` | 目录、导航、主题、排版及滚动位置 |
| `assets/state.js` | 本地状态读取、容错与范围约束 |
| `assets/reader.css` | 阅读及自适应样式 |
| `watch.mjs` | 源文件变化触发本地预览重建 |
| `test/reader.test.mjs` | 发布边界、导航、内容转义和状态容错验收 |

预览路由：`index.html`（简介/目录）、`zh/NN.html`（章节）。相对链接可放在静态托管子路径下，不要求域名根目录。英文仅有manifest元数据；实际路由在译文审定后按同ID建立。
