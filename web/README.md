# 《重返星舰》双语网页阅读器｜规划阶段

**最终目标已确认：中文原著＋英文文学译本＋中英文一键切换的网站。** 当前仓库具有23篇中文创作初稿、尚待作者确认与终审；**没有23篇英文翻译稿，也没有已开发部署的阅读网站**。

## 内容入口

- **中文：** [`manuscript/zh/`](../manuscript/zh/README.md)，23篇已写到结局，仍在文学编辑与作者审定阶段。
- **英文：** [`manuscript/en/`](../manuscript/en/README.md)，只有译稿目录与23章对应标题的工作清单，**0/23英文章节完成**。
- **双语章节元数据：** [`content-manifest.json`](content-manifest.json)；相同00—22章ID，分别追踪中文/英文内容路径、编辑状态、来源SHA和发布许可。
- **语言与阅读器规范：** [`I18N.md`](I18N.md)；包含路由、中文/英文切换、段落对照、阅读进度与不公开未批准正文的规则。
- **翻译及发行工作流：** [`docs/bilingual-publication-plan.md`](../docs/bilingual-publication-plan.md)，[暂定英文专名词汇表](../docs/translation-glossary.md)。

## 计划提供的体验

| 功能 | 最终要求 |
| --- | --- |
| 作品首页 | 中文/英文作品名、经作者许可的简介、当前可公开阅读版本 |
| 语言切换 | **中文 / English** 一键切换，同章对照优先保留阅读位置；缺少/未发布译本时明确提示，不404或暴露未审稿 |
| 目录 | 00引言优先、第一至22章；章节编号固定，语言标题各自自然 |
| 章节导航 | 上一章、下一章、回目录、连续阅读；同语言内保持导航 |
| 移动/桌面适配 | 手机、平板和电脑合理正文宽度、字号/行距与触控区 |
| 阅读主题 | 深浅模式、正文排版及语言字型选择，设置可保留 |
| 阅读进度 | 本地记录作品/语言/章节/锚点；不把不同语言像素位置机械同步 |
| 内容同步 | 只从Git中经过作者批准的版本构建，中文更新后对照译文若失配先标记待更新 |
| 可访问性 | 键盘导航、正确语言语义、对比度、结构化标题与图片文字替代 |
| 发布安全 | `publish_approved` 默认为false，**仓库Public并不构成读者网站正式发布许可** |

## 实施顺序

1. 完成中文全书文学终审、角色/科学/时序连续性校对，并确定作者愿意采用的结局版本与可公开的中文版本。
2. 确认英文名字与术语、完成23章英语文学译文和双语对读；每章记录其中文已批准源版本SHA。
3. 构建静态双语阅读器，内容清单只生成实际已批准的语言页面。
4. 测试同章语言切换、段落锚点、未翻译状态、手机/桌面布局、深浅主题、阅读位置、Git更新后不误发布。
5. 经作者明确批准后部署网站，并核对真实可访问网址。

**注意：** 文件规划本身不是部署，现阶段不存在可供读者正式访问的网站地址。若将来决定提前开发“内部预览”，须与正式公开版本明确隔离，避免将待审D路线初稿误当作已定稿。
