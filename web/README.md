# 网页阅读平台｜后续阶段

当前只规划，不开发或发布。正文稳定后，以`manuscript/zh/`为唯一内容来源；sources、历史助手稿、未确认大纲不进入公开章节目录。

| 功能 | 实施要求 |
|---|---|
| 首页 | 作品中文/英文名、经核准简介、更新进度、开始阅读 |
| 目录与导航 | 引言首位，按章排序，上一章/下一章、回目录与连续阅读 |
| 响应式 | 手机和电脑适配，合理正文宽度与触控区域 |
| 阅读主题 | 深色/浅色，字号与行距调节，设置持久保存 |
| 阅读进度 | 本地保存章节、段落锚点及位置；新章更新后不丢进度 |
| 持续同步 | 从Git确认正文生成章节清单与页面，提交检查通过后同步；草稿不得误发布 |
| 可访问性 | 键盘导航、语义标题、主题对比度、图片替代文字 |

阶段：内容格式与章节元数据确定→静态阅读器→移动端/主题/进度验收→部署可公开网址→按章节持续更新。技术栈与托管方案待网站阶段根据实际仓库选择，当前没有发布地址或虚构完成状态。
